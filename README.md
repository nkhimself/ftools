# Logarina (لوگارینا)
Persian food-engineering calculators. Static site, no build step on the server.

Pages: home, thermal, formulation, fitting, dairy, bakery, beverage, about, login, signup.
Login and signup are DEMO pages: they validate input in the browser and save/send nothing.
search-index.js is generated by build_pages.py (in the source zip); do not edit it by hand.

GitHub Pages: Settings > Pages > Deploy from branch > main / root.
